# Loading Sonar Control

Loading Sonar Control is a StreamDock plugin for controlling SteelSeries GG Sonar on Windows.

## Features

- Sonar connection and mode status
- Channel volume and mute controls
- Fixed channel volume presets
- Output and microphone device selection
- ChatMix control
- Classic and Streamer mode switching
- Mixer scenes
- Desktop status display for volume, mute, devices, ChatMix, mode, and scenes

## Requirements

- Windows 10 or later
- SteelSeries GG with Sonar enabled
- StreamDock 3.10.188.226 or later
